# 現場操作手冊

> ✍️ 本文件由 Claude 撰寫（2026-11），內容依據原始程式碼與試算表整理；系統本身由 PG企鵝 設計、Gemini 產生程式碼。

> 依照程式行為整理的建議流程。所有頁面都是同一個 Apps Script 網頁應用程式網址，用 `?page=` 切換。

## 設備配置

| 位置 | 裝置建議 | 開啟的網址 | 備註 |
|---|---|---|---|
| 收銀台 | 橫放平板 | `…/exec` | 畫面左 2/3 是菜單、右 1/3 是購物車；數字鍵盤為唯讀輸入框，不會跳出系統鍵盤 |
| 關東煮區 | 平板或筆電 | `…/exec?page=kds` | 顯示關東煮與所有套餐，每 5 秒刷新 |
| 飲料區 | 平板或筆電 | `…/exec?page=kds_drinks` | 只顯示飲料，每 5 秒刷新 |
| 攤位前方 | 電視／大螢幕 ＋ 喇叭 | `…/exec?page=ocs` | 開啟後**點一下畫面**才會進入全螢幕並啟用語音（瀏覽器規定語音必須由使用者操作觸發） |
| 取餐櫃台 | 手機或平板 | `…/exec?page=pickup` | 每 3 秒刷新，列出所有「待取餐」訂單 |

- 收銀用的裝置要登入 Google 帳號，「點餐人員」欄位才會記錄是誰收的錢。
- 多台 POS 可以同時使用，後端的鎖會讓送單排隊，庫存不會被重複扣。

## 開店前

1. **核對菜單**：在 `菜單` 工作表確認價格與 D 欄庫存都是今天的備料量。
2. **核對範本**：新增或改名的品項，要同步更新 `Order#0` 的 C–F 欄（見 [sheets.md](sheets.md#c-f-欄品項明細)）。
3. **確認部署**：Apps Script 改過程式後要重新部署（「管理部署作業」→ 編輯 → 新版本），或請大家使用最新的部署網址。
4. **開啟所有裝置**，並確認畫面右上角沒有出現「連線錯誤」。
5. **測試一筆訂單**：用 POS 點一份最便宜的品項 → 兩台 KDS 依序「接單」「完成」→ OCS 播報號碼 → Pickup「取餐完成」。測完記得把庫存加回去。

> 取餐號碼每天從 1 開始，是依最後一張訂單的日期判斷。前一天測試的訂單不會影響今天的號碼；同一天測試的話，正式營業會從測試之後的號碼接續。

## 營業中

### 收銀（POS）

1. 上方分類頁籤切換「全部／套餐／關東煮／飲料」，點品項加入購物車。
2. **E 餐**會跳出選擇視窗，$15、$20、$25 三區各選一樣才能加入；已售完的品項會變灰。
3. 購物車可用 `−`／`＋` 調數量，或按垃圾桶刪除。
4. 按「結帳 (送出)」→ 用數字鍵盤輸入實收金額，或按「剛好／100／500／1000」→ 確認找零 →「確認送出訂單」。
5. 畫面顯示**取餐號碼**，告知顧客後按「完成 (關閉)」，購物車會清空並重新載入庫存。

### 廚房（KDS）

- 新訂單是**藍色**卡片，按「接單 (Preparing)」後變**橘色**，做好按「完成 (Ready)」卡片就會消失。
- 卡片依送單順序排列（先來先做）。套餐會展開列出內容，E 餐每一份分開顯示。
- 同時有關東煮和飲料的訂單，要**兩站都按完成**才會出現在叫號螢幕的「待取餐」。

### 叫號（OCS）

- 左邊「準備中」顯示製作中的號碼（最新的在前），右邊「待取餐」是做好的號碼。
- 新號碼進入「待取餐」時會語音播報「N 號，請取餐」。

### 取餐（Pickup）

- 顧客報號碼 → 找到對應卡片 → 交餐 → 按「取餐完成 (Completed)」，號碼就會從叫號螢幕上移除。

## 常見狀況

| 狀況 | 處理方式 |
|---|---|
| POS 顯示「XXX 庫存不足」 | 其他收銀台剛好賣掉了，請顧客改點；或到 `菜單` D 欄補庫存，POS 送單後會自動重新載入 |
| 畫面出現「連線錯誤」 | 通常是網路不穩或 Apps Script 暫時過載，關閉錯誤視窗會自動重試 |
| 叫號沒有聲音 | 確認進入頁面時有點擊畫面、電視音量與瀏覽器分頁沒有靜音 |
| 訂單卡在 KDS 或待取餐 | 到 `訂單` 工作表把該列 F 欄改成 `completed`。若 KDS 還看得到，最多 2 分鐘後快取過期就會消失；有任何新的寫入也會立即刷新 |
| 送錯單要退款 | 系統沒有作廢功能：到 `菜單` 手動加回庫存，並把 `訂單` 該列狀態改成 `completed`，另外記錄退款 |

## 收攤

1. 確認 `訂單` 工作表沒有停在 `pending`／`preparing`／`ready_for_pickup` 的訂單。
2. 營業額可用 `訂單` 工作表 E 欄加總（以當天日期篩選 C 欄）。
3. 活動結束後，到 Apps Script「管理部署作業」**封存網頁應用程式部署**。部署設定是「任何人皆可存取、以部署者身分執行」，網址留著的話，任何人都能操作這份試算表。
